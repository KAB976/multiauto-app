Comment ça fonctionne
On utilise des alias Gmail — le signe + dans une adresse Gmail.
Exemple : somalan2000+abdou@gmail.com arrive dans votre boîte somalan2000@gmail.com
Firebase les considère comme des adresses différentes ✅
Étapes à suivre dans Firebase Console
1. Allez sur console.firebase.google.com
2. Projet multiauto-depannage → Authentication → Users
3. Pour chaque utilisateur : cliquez les 3 points ···
4. Cherchez "Modifier l'email" ou modifiez directement
